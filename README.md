# ローカルモデル診断書

手元で動かしている言語モデルを**10の軸**で測って、診断書を1枚出します。

    説制俺誠開-98568

前の5文字が性格、後ろの5桁が性能です。

**測るのはあなたのPCの中だけです。** モデルが答えた本文はどこへも送られません。
このプログラムが外へ出す通信は、あなたが指定したアドレス（既定 `127.0.0.1`）だけです。

---

## 使い方

    python -m pip install -r requirements.txt
    python 診断.py --port 8080

複数のモデルが載っているときは1本を選びます。

    python 診断.py --port 11434 --model "qwen3:8b" --name "Qwen3 8B"

| 指定 | 意味 |
|---|---|
| `--port` | **必須。** OpenAI互換の口の番号 |
| `--host` | 別のPCで動かしているとき（既定 `127.0.0.1`） |
| `--model` | 複数載っているときに1本を選ぶ |
| `--name` | 診断書に出す表示名 |
| `--engine` | 診断書の右上に出す一行（例 `llama.cpp :8080 / Q4_K_M`） |
| `--out` | 診断書の出力先（既定 `診断書/`） |
| `--redo` | 済んだ測定もやり直す |

**途中で止まっても、同じコマンドをもう一度流せば続きから測ります。**

所要は30分〜3時間。モデルの速さで変わります。

---

## 先にやっておくこと

**文脈を 32,768 以上にしてください。** この診断は3,500語の文書を読ませます。

| ソフト | やり方 |
|---|---|
| Ollama | 環境変数 `OLLAMA_CONTEXT_LENGTH=32768` を入れて再起動。または Modelfile に `PARAMETER num_ctx 32768` |
| llama.cpp | 起動時に `-c 32768` |
| LM Studio | モデルの設定で Context Length を 32768 へ |

**Ollama の既定は 4,096 です。** そのままだと読解力の途中で必ず止まります。
（診断は始める前にここを確かめて、足りなければ直し方を出して止まります）

## 10の軸

**性格（漢字1文字）**

| 文字 | 軸 | 高い／低い |
|---|---|---|
| 直／説 | 率直さ | 前置きを置かない／前置きが長い |
| 制／暴 | 自制心 | 答えが出たら止まる／確認をやめない |
| 規／俺 | 正答率 | 規則どおりに正解する／自己流で外す |
| 誠／偽 | 正直さ | 無い物を無いと言う／それらしく埋める |
| 開／禁 | 無検閲度 | 際どい題材にも答える／断る題材がある |

**性能（0〜9。実測の百分率を10で割った数）**

到達率 ／ 読解力 ／ 日本語の質 ／ 実作業 ／ 画像を見るか
